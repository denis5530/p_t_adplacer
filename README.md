# Тарифы — AdPlacer

Страница «Тарифы» в стиле SaaS (Stripe / Notion / Linear): минимализм, чёткая структура, без лендингового маркетинга.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
npx serve .
# или
python3 -m http.server 8080
```

## Сценарии отображения

В консоли браузера (F12) можно переключать сценарии:

```js
// Нет активного тарифа
AdPlacerTariffs.setScenario('noTariff');

// Активный тариф, всё ок
AdPlacerTariffs.setScenario('active');

// Автопродление включено, монет достаточно
AdPlacerTariffs.setScenario('autoRenew');

// Недостаточно монет для автопродления
AdPlacerTariffs.setScenario('insufficientCoins');

// Тариф заканчивается скоро (жёлтый статус)
AdPlacerTariffs.setScenario('endingSoon');

// Ручная настройка
AdPlacerTariffs.setBalance(500);
AdPlacerTariffs.setAutoRenew(false);
```

## Структура

- **Блок баланса** — сверху, компактно: баланс в монетах + «Пополнить баланс». При нехватке монет для продления — предупреждение и «Пополнить сейчас».
- **Нет тарифа** — карточка «У вас нет активного тарифа» + кнопка «Выбрать тариф».
- **Текущий тариф** — название, дата окончания, статус (Активен / Заканчивается скоро), переключатель автопродления, стоимость продления и достаточность монет.
- **4 тарифа** — карточки: Старт, Базовый, Бизнес, Про. Кнопки: «Выбрать тариф», «Текущий тариф» (disabled), «Недоступно» (понижение), «Расширить тариф».
- **Апгрейд** — модальное окно с подтверждением и суммой списания.

Цвета статусов: зелёный — ок, жёлтый — заканчивается скоро, красный — не хватает монет.
